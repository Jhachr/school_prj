# 流程验证 Demo

## 用途

这个页面用于第一次客户沟通，帮助客户直观看到科研立项引导助手的阶段、阻断条件、来源状态、质量等级和阶段性产物。

它不是正式产品运行时，不接入模型 API、不现场调用实时文献检索 API、不上传文件、不生成可直接提交的申报书。页面会用 `demo_fixture` 展示文献检索结果、前沿研究依据和文献综述草稿应如何进入流程；正式版本应在成熟 Harness 中运行科研立项 Skill，并接入真实文献检索能力。

## 启动

```bash
python3 -m http.server 4173 -d demo
```

浏览器访问：

```text
http://localhost:4173
```

也可以直接打开 `demo/index.html`，但建议使用本地静态服务器，避免浏览器对 ES Modules 的本地文件限制。

## 演示方式

1. 从初始输入“我想做 AI+教育”开始。
2. 点击“下一步”，展示系统如何阻断空泛输入并持续追问。
3. 观察右侧“阶段状态”，确认 8 个客户阶段和 10 个内部状态如何对应。
4. 切换“已确认”“缺失项”“最终产物”，展示来源标记和 B 级允许产物。
5. 结束时让客户确认流程、产物、质量规则和资料责任。

## 测试

```bash
node --test demo/tests/*.test.mjs
```

测试覆盖：

- C/B/A 唯一判定规则
- 直播电商演示案例稳定判 B
- `demo_fixture`、`user_confirmed`、`missing` 来源标记
- B 级生成文献综述草稿，但不生成 `proposal_draft`
