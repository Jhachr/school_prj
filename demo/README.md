# 流程验证 Demo

## 用途

这个页面用于第一次客户沟通，帮助客户直观看到科研立项引导助手如何从模糊想法出发，逐步追问、纠偏、推荐课题方向，并生成阶段性材料。

它不是正式产品运行时，不接入模型 API、不现场调用实时文献检索 API、不上传文件、不生成可直接提交的申报书。页面会用示例依据展示文献检索结果、前沿研究依据和文献综述草稿应如何进入流程；正式版本应在成熟 Harness 中运行科研立项 Skill，并接入真实文献检索能力。

## 启动

```bash
python3 -m http.server 4173 -d demo
```

浏览器访问：

```text
http://localhost:4173
```

页面入口：

- 操作原型验证：`http://localhost:4173/index.html`

也可以直接打开 `demo/index.html`，但建议使用本地静态服务器，避免浏览器对 ES Modules 的本地文件限制。

## 操作原型演示方式

1. 从初始输入“我想做 AI+教育”开始。
2. 点击“下一步”，展示系统如何阻断空泛输入并持续追问。
3. 观察顶部 8 个业务阶段，和客户确认每一步是否符合真实申报过程。
4. 观察右侧“阶段判断”和“申报书字段映射稿”，说明系统为什么追问，以及已确认内容如何进入申报书栏目。
5. 结束时让客户确认流程、产物、质量规则和资料责任。
