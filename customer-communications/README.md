# Customer Communications

这里用于保存与客户沟通、访谈、调研相关的材料。

## 目录说明

- `raw/`：存放原始记录，例如访谈逐字稿、会议纪要、聊天记录、问卷结果、客户提供的背景材料。
- `summaries/`：存放整理后的总结，例如需求洞察、问题清单、决策记录、行动项、风险判断。

## 建议记录格式

文件名建议使用：

```text
YYYY-MM-DD-topic.md
```

原始记录建议包含：

- 时间
- 参与人
- 沟通方式
- 原始内容
- 附件或来源链接

总结记录建议包含：

- 本次沟通目标
- 关键结论
- 客户痛点
- 明确需求
- 未确认问题
- 下一步行动
