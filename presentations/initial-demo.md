# 专科院校教师科研助手项目展示

## 项目目标

为专科院校缺少科研申报经验的一线教师,提供一个科研立项引导助手。通过有规则的对话,帮助老师从模糊的工作困扰出发,逐步梳理清楚研究问题、研究方法、成果形式,最终生成可进入课题申报的结构化方案。

产品定位不是替老师代写材料,而是当一个懂科研申报的教练,引导老师自己想清楚课题。

## 首版聚焦场景

第一版只覆盖一个核心场景:**小白老师不知道申报什么课题**。

老师可能没有明确课题方向。助手从老师的岗位、教学工作、痛点、学校要求出发,帮助老师发现可申报课题,并把朴素表达转化为结构化、符合申报要求的材料。

典型路径:

```text
了解教师背景
-> 挖掘教学或工作问题
-> 结合申报指南与政策
-> 推荐课题方向
-> 方向确认
-> 澄清研究问题、方法和成果
-> 生成申报书初稿
-> 质量检查与追问
-> 输出课题方案卡与申报书字段映射稿
```

## 首版能力边界(本次交付)

- 科研立项引导:从选题到申报书初稿的完整对话引导
- 纠偏收敛:拒绝空泛课题,持续追问直至收敛为可落地方向
- 关键节点人工确认:方向、研究问题、方法、成果、初稿五个节点必须用户确认
- 质量检查与追问:十维检查、A/B/C 分级,薄弱环节自动追问
- 可视化产出:课题方案卡、申报书字段映射稿
- 文献与政策支撑:首版用演示数据模拟,标注来源,不伪造引用

## 产品差异化

与直接把问题丢给大模型的区别:

- **引导而非代写**:不直接生成课题,而是通过提问帮老师自己想清楚
- **纠偏收敛**:识别空泛方向并持续追问,把"我想做 AI+教育"收敛为可落地课题
- **质量驱动**:每个阶段有通过条件和阻断规则,质量不足不进入下一环节
- **成果导向**:强制要求非论文的可复用成果,匹配客户对工具性、流程性的要求
- **可追溯**:区分用户确认与 AI 推测,每条内容标注来源依据

## 远期规划(不在首版交付)

以下能力已识别为产品方向,但明确不在第一次交付范围,避免客户误解首版覆盖度:

- 论文写作与润色
- 真实文献检索与综述自动整理(首版仅模拟)
- 教师科研成果材料整理
- 学校科研管理流程适配与系统集成
- 进阶教师申报更高层级课题
- docx 模板自动填充
- 完整知识库与历年立项分析

> 首次交付核心目标:让客户确认这套立项引导逻辑是懂科研申报的教练,显著优于普通大模型自由聊天。

## 下一步计划

1. 用最小 Demo 向客户校准提问顺序与质量标准。
2. 收集客户申报书模板、优秀申报书和申报指南。
3. 根据客户确认结果调整流程规则与质量检查表。
4. 在真实材料基础上迭代第二版 Demo。
