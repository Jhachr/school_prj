# 专科院校教师科研助手项目展示

## 项目目标

为专科院校教师提供一个科研辅助助手，帮助教师在课题申报、论文写作、文献梳理、项目材料准备等科研工作中降低门槛、提高效率。

## 建设思路

本项目采用“仓库即上下文”的方式推进：

- 客户沟通记录持续沉淀
- 需求理解和调研结论可追溯
- 核心交付物以 Skill 形式迭代
- 展示材料和交付文档统一管理

## 初步能力方向

- 科研选题辅助
- 课题申报书结构化撰写
- 文献检索与综述整理
- 论文框架生成与润色
- 教师科研成果材料整理
- 学校科研管理流程适配

## 下一步计划

1. 收集客户访谈和真实科研场景。
2. 总结教师高频任务和关键痛点。
3. 明确首版科研助手 Skill 的使用边界。
4. 基于试点场景完成第一版交付演示。
