# 专科院校教师科研立项引导助手

## 本期目标

本期聚焦一个核心问题：帮助缺少科研申报经验的老师，从朴素的教学或工作问题出发，逐步形成可申报的课题方案，并生成申报书准备材料。

本期不是完整科研助手交付，也不覆盖论文投稿、结题管理、学校系统集成等远期能力。

## 客户诉求复述

客户希望系统不是简单替老师写材料，而是像科研立项教练一样，引导老师想清楚：

- 要解决什么真实问题
- 为什么这个问题值得研究
- 准备用什么方法解决
- 最终形成什么可复用成果
- 如何转化为符合学校格式的申报书材料

## 首版场景

首版只演示“小白老师不知道申报什么课题”的场景。

本次 demo 选用学校专业目录中的 **管理与数字经济学院 - 网络营销与直播电商** 作为案例专业。选择这个专业，是因为它有清晰的实训场景、岗位任务、直播数据和可复用成果，适合展示“空泛想法如何收敛为可申报课题”。

典型用户从一句很空泛的话开始：

```text
我想做 AI+教育，帮我写个课题申报。
```

系统不会直接生成申报书，而是通过追问把方向收敛到具体课程、学生群体、教学环节、可获得数据和成果形式。

## 流程拆分

```text
教师画像采集
-> 空泛意图纠偏
-> 工作问题挖掘
-> 课题方向推荐
-> 研究问题澄清
-> 文献与政策支撑
-> 方法与成果设计
-> 申报材料生成与质检
```

## 产品差异点

1. 不是自由聊天，而是有阶段、有条件、有追问的申报流程。
2. 空泛输入不会直接生成，必须先收敛到真实问题。
3. 每个关键结论区分用户确认、AI 推测、材料依据和待验证内容。
4. 成果不只是一篇论文，还要强调工具、流程、案例、量表、资源包等可复用产出。
5. 最终输出可映射到申报书栏目，并明确标注待补充项。

## Demo 最终产物

本次 demo 预计展示三类产物：

- 专业选择依据：为什么选网络营销与直播电商作为首版案例
- 课题方案卡：问题、对象、方法、成果、依据、风险、待补充信息
- 申报书字段映射稿：把已确认内容放入通用申报书栏目
- 待补充清单：真实模板、申报指南、优秀案例、评审标准等

## 需要客户确认

演示后希望客户确认：

- 提问顺序是否符合老师真实申报过程
- 选题推荐方式是否认可
- 哪些节点必须人工确认
- 最终输出结构是否适合作为申报准备材料
- 哪些质量规则需要科研处或专家补充

## 下一步

客户提供申报书模板、优秀申报书、申报指南和评审标准后，我们将把 demo 从通用流程升级为贴合学校真实申报要求的版本。
