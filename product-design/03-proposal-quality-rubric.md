# 申报材料质量检查规则

## 用途

这份规则用于驱动系统判断：什么时候继续追问，什么时候只能生成阶段性材料，什么时候可以额外生成申报书结构化内容草稿。

规则必须与 `demo/src/state.mjs` 中的 `evaluateGrade` 保持一致。

## 判定原则

```text
先判 C -> 再判 B -> 最后判 A
```

不得输出“A 或 B”。每次只能给出一个确定等级。

## 来源状态要求

| 来源状态 | 含义 | 质量规则 |
|---|---|---|
| `user_confirmed` | 用户明确表达或确认 | 可以作为用户事实 |
| `ai_suggestion` | AI/系统建议，尚需用户采纳 | 不能替代用户确认 |
| `material_verified` | 来自可追溯真实材料 | 可以作为真实依据 |
| `demo_fixture` | 演示占位数据 | 只能用于流程演示 |
| `missing` | 当前缺失 | 必须进入待补充清单 |

## C 级：继续追问，不生成申报材料

任一条件成立即判 C：

| 条件 | 对应字段 | 系统动作 |
|---|---|---|
| 教师画像尚未确认 | `teacher_profile` | 回到教师画像采集 |
| 真实工作问题尚未建立 | `problem_candidates` | 回到工作问题挖掘 |
| 课题方向尚未确认 | `selected_topic` | 回到课题方向推荐与确认 |
| 研究对象、场景或研究问题尚未确认 | `research_question` | 回到研究问题澄清 |

允许输出：

- 问题澄清提问
- 方向收敛建议
- 示例选项

不允许输出：

- 课题方案卡
- 申报书字段映射稿
- 申报书结构化内容草稿

## B 级：可生成阶段性材料

C 级条件不成立，但任一条件成立即判 B：

| 条件 | 对应字段 | 风险标记 |
|---|---|---|
| 方法路径或数据来源仍需细化 | `method_plan` | `missing` 或 `ai_suggestion` |
| 非论文成果尚未确认 | `deliverables` | `missing` |
| 真实申报指南尚未接入 | `evidence_basis.guide` | `demo_fixture` 或 `missing` |
| 真实文献检索结果尚未接入 | `evidence_basis.literature` | `demo_fixture` 或 `missing` |
| 真实申报模板尚未接入 | `proposal_mapping.template` | `missing` |

允许输出：

- 课题方案卡
- 文献综述草稿
- 申报书字段映射稿
- 待补充清单
- 质量结果

不允许输出：

- 正式申报书草稿
- 未标注依据的文献综述
- 可直接提交的表述

当前直播电商 Demo 使用演示指南和缺失模板，稳定判为 B。

## A 级：可额外生成结构化内容草稿

只有同时满足以下条件才判 A：

1. 教师画像已确认。
2. 真实工作问题已确认。
3. 课题方向已确认。
4. 研究问题已确认。
5. 方法和数据来源可执行。
6. 至少一个非论文成果已确认。
7. 真实申报指南来源为 `material_verified`。
8. 真实文献检索结果和综述依据来源为 `material_verified`。
9. 真实申报模板来源为 `material_verified`。

允许输出：

- 课题方案卡
- 文献综述草稿
- 申报书字段映射稿
- 待补充清单
- 质量结果
- 申报书结构化内容草稿

仍然必须声明：A 级内容需要人工和专家审核，不能称为可直接提交。

## 检查维度

| 维度 | 证据字段 | 达标表现 | 不达标动作 |
|---|---|---|---|
| 真实问题 | `problem_candidates` | 来自具体教学/工作场景 | 判 C，继续追问 |
| 问题具体性 | `research_question` | 有对象、场景、痛点、目标 | 判 C，继续追问 |
| 教师适配 | `teacher_profile` | 与教师课程/岗位相关 | 判 C，重采画像 |
| 方法可执行 | `method_plan` | 有对象、数据、周期、实施路径 | 判 B，标记待补充 |
| 非论文成果 | `deliverables` | 至少一个可复用成果 | 判 B，追问成果形式 |
| 申报价值 | `evidence_basis` | 能说明与学校/政策/专业建设相关 | 判 B，待科研处确认 |
| 政策依据 | `evidence_basis` | 真实材料或明确演示标记 | 判 B，标记来源 |
| 文献支撑 | `evidence_basis` | 有真实检索结果、前沿研究摘要和综述草稿 | 判 B，待真实检索 |
| 模板适配 | `proposal_mapping` | 能映射到申报书字段 | 判 B，待真实模板 |

## 测试案例

### 案例 1：空泛输入

输入：

```text
我想做 AI+教育。
```

判定：C。

原因：教师画像、真实问题、课题方向和研究问题均未建立。

### 案例 2：直播电商演示案例

输入：

```text
李老师确认网络营销与直播电商专业课程场景、直播任务全流程问题、岗位任务导向课题、研究问题、可执行方法和非论文成果。
当前指南和文献综述依据为 demo_fixture，申报模板为 missing。
```

判定：B。

允许输出：课题方案卡、文献综述草稿、申报书字段映射稿、待补充清单、质量结果。

### 案例 3：真实材料齐备

输入：

```text
案例 2 的所有核心字段已经确认，且真实申报指南和真实申报模板均为 material_verified。
```

判定：A。

允许额外输出：申报书结构化内容草稿。
