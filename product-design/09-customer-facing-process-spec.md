# 科研立项引导流程技术说明书

## 文档目的

这份文档用于向客户说明：我们如何把“帮助老师完成科研立项申请”的诉求拆解为可执行流程。它既是阶段性客户交付物，也可作为后续 Agent/Skill 建设的流程蓝图。

## 本期建设目标

本期只聚焦科研立项申请，特别是“小白老师不知道申报什么课题”的场景。

目标不是让 AI 直接替老师写完材料，而是让系统像科研立项教练一样，通过有规则的对话帮助老师完成三件事：

1. 从真实工作中找到可研究问题。
2. 将问题转化为可申报课题方案。
3. 形成可进入申报书的结构化材料。

## 整体流程

```text
教师画像采集
-> 空泛意图纠偏
-> 工作问题挖掘
-> 课题方向推荐
-> 研究问题澄清
-> 文献与政策支撑
-> 方法与成果设计
-> 申报材料生成与质检
```

## 阶段说明

| 阶段 | 解决什么问题 | 核心动作 | 阶段产出 | 关键因素 |
|---|---|---|---|---|
| 教师画像采集 | 不知道老师是谁、做什么，就无法推荐课题 | 采集院系、岗位、课程、工作内容、科研基础 | 教师画像摘要 | 必须落到真实课程或工作场景 |
| 空泛意图纠偏 | 老师常以“AI+教育”“提升质量”等宽泛方向开始 | 拒绝直接生成，追问具体课程、学生、环节、数据 | 收敛后的问题域 | 展示产品区别于普通聊天的关键环节 |
| 工作问题挖掘 | 把日常困扰变成可研究问题 | 追问痛点、对象、频率、影响和已有尝试 | 候选问题清单 | 问题必须真实、具体、可观察 |
| 课题方向推荐 | 老师不知道哪个方向适合申报 | 生成 2-3 个方向，说明理由、成果和风险 | 课题方向候选卡 | 不替老师决定，必须让老师选择 |
| 研究问题澄清 | 课题名称不等于研究问题 | 用对象、场景、问题、方法、评价方式组织表达 | 研究问题草案 | 必须可回答、可实施、可评价 |
| 文献与政策支撑 | 课题需要说明为什么值得做 | 引入申报指南、政策文件、文献或优秀案例 | 依据说明 | 演示数据和真实材料必须区分 |
| 方法与成果设计 | 课题不能只有想法，要能实施和结题 | 设计方法路径、数据来源、实施计划和成果形式 | 方法路径和成果清单 | 成果不能只有论文，要有可复用成果 |
| 申报材料生成与质检 | 把思考转化为申报书准备材料 | 生成方案卡、字段映射稿，检查缺口和风险 | 方案卡、字段映射稿、待补充清单 | 缺硬性门槛时不生成完整初稿 |

## 每阶段关键产出

### 1. 教师画像摘要

记录老师的岗位、课程、工作场景、已有资源和科研基础。

用途：

- 支持个性化提问
- 避免推荐与教师工作无关的课题
- 后续形成教师科研画像

### 2. 课题方向候选卡

每个候选方向包含：

- 暂定课题名称
- 对应真实问题
- 研究对象
- 方法路径
- 预期成果
- 申报理由
- 主要风险

用途：

- 帮老师比较方向
- 让客户看到系统不是只给一个答案
- 保留可追溯的选择过程

### 3. 研究问题草案

用一句结构化表达说明课题要研究什么。

建议格式：

```text
在某类对象/场景中，如何通过某种方法，解决某个具体问题，并用某种方式评价效果？
```

### 4. 依据说明

说明课题和申报指南、政策方向、文献现状、优秀案例之间的关系。

每条依据都必须标记：

- 用户确认
- AI 推测
- 材料依据
- 演示数据
- 待验证

### 5. 方法路径和成果清单

方法路径说明怎么做，成果清单说明最后留下什么。

成果必须包含至少一个非论文成果，例如：

- 教学案例
- 工作流程
- 评价量表
- 课程资源包
- 实施方案
- 工具模板

### 6. 申报书字段映射稿

把已确认内容放入申报书栏目中，同时标记缺失内容。

用途：

- 让客户看到最终材料如何落到申报书
- 指导后续 DOCX 模板填充
- 暴露还需要补充哪些真实材料

## 关键质量规则

| 规则 | 系统行为 |
|---|---|
| 输入过于空泛 | 不生成课题，先追问收敛 |
| 缺少真实问题 | 不进入课题方向推荐 |
| 缺少研究对象或场景 | 不生成研究问题 |
| 缺少可执行方法 | 只生成方案摘要，不生成完整初稿 |
| 成果只有论文 | 必须追问可复用成果 |
| 使用演示政策/文献 | 必须标记为演示数据 |
| AI 推测内容 | 必须等待用户确认 |

## 本期成功标准

第一次 demo 成功，不以生成一份完整正式申报书为标准，而以客户确认以下事项为标准：

1. 流程是否符合老师真实科研申报过程。
2. 追问是否能帮助老师把问题想清楚。
3. 阶段产出是否有价值。
4. 质量规则是否符合科研处判断。
5. 后续接入真实模板和材料后，是否可以进入试点。
