# Demo 专业选择依据

## 选择结论

第一次客户演示建议选用：

```text
管理与数字经济学院 - 网络营销与直播电商
```

## 为什么不继续使用机械制图案例

原机械制图案例能够展示“岗位任务导向 + 评价量表”的通用逻辑，但它不是客户当前提供的学科设置中的直接专业表达。为了让客户更有代入感，demo 应切换到学校真实专业目录中的专业。

## 候选专业比较

| 专业 | 优点 | 风险 | 判断 |
|---|---|---|---|
| 网络营销与直播电商 | 实训场景强、数据可观察、岗位任务清晰、成果形式丰富 | 需要避免变成泛泛“AI+直播” | 最适合首版 demo |
| 智能体技术应用 | 与 AI 主题高度相关，容易体现技术前沿 | 容易让客户误以为首版要做复杂 AI 技术课题 | 可作为后续进阶案例 |
| 数字非遗设计与制作 | 学校特色鲜明，文化与数字技术结合度高 | 需要更多非遗项目和文化资源材料支撑 | 适合第二轮特色案例 |
| 护理/健康管理 | 问题真实，研究场景稳定 | 涉及医学健康边界，演示需更谨慎 | 暂不作为首版 |
| 学前教育 | 教研场景经典，客户容易理解 | 与学校差异化专业特色弱一些 | 可作为通用教育类备选 |

## 选择依据

学校官网专业介绍显示，网络营销与直播电商专业具有以下特点：

1. 专业强调“实践性、技术性、多元性”。
2. 课程体系需要与行业产业需求紧密结合。
3. 专业建设遵循 OBE 理念，强调能力培养和产出导向。
4. 校内配备直播实训室、摄影实训室、营销实训室和综合直播基地。
5. 就业方向包括网络营销、直播电商、新媒体运营、数据分析等岗位。

这些特点和科研立项 demo 的需求高度匹配：

- 有真实课程和实训场景。
- 有岗位任务可转化。
- 有学生作品、直播数据、复盘作业等可观察材料。
- 容易形成非论文成果，如任务包、评价量表、复盘模板、案例库。

## Demo 课题方向

建议演示课题：

```text
岗位任务导向的直播电商实训教学改革研究
```

核心研究问题：

```text
在专科网络营销与直播电商专业的新媒体直播运营课程中，如何基于企业真实直播运营岗位任务重构实训项目，并通过数据复盘评价量表提升学生直播策划、执行和复盘能力？
```

## 后续可扩展案例

如果客户希望展示更多院系覆盖，可追加两个备选 demo：

1. 数字非遗设计与制作：非遗数字化项目教学与文创成果转化。
2. 智慧健康养老服务与管理：养老服务场景任务导向的照护能力训练。
