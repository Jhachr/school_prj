# Literature Review Longform Template

```markdown
## Literature Review Longform

### Retrieval Record

Run directory:

| Source | Query | Date | Result / Failure | Included Records | Coverage And Access Limits |
|---|---|---|---|---|---|

### How Existing Studies Explain Or Handle The Problem

Write checked synthesis with claim markers such as `[C01]`. For abstract-only evidence, state “尚未读取全文”.

### Practices, Supporting Evidence, And Limiting Evidence

Include differences or counterevidence only when they were actually observed; do not fill this section mechanically.

### Implications For This Teacher's Scene

Separate literature findings, assistant interpretation, and recommended next action.

### What Cannot Yet Be Concluded

State verification, database coverage, query, language, and full-text access limits. Describe any research gap as a clue within this scope, not as proof that no research exists.

### References

Use one line per cited record and include `[record:<record_id>]`.

### Questions For The Teacher

### Missing Or Unverified Evidence

Explain statuses in Chinese when present: `verified`（已核验）, `unresolved`（暂未核验：当前公共源无法确认）, `conflicted`（信息冲突：DOI、标题、作者或年份存在冲突）, `rejected`（已排除：标识明确不存在或记录明显错误）.

### Traceability Check

Record the association-check result and the separate human content-review result. A passing script does not prove semantic support.
```

Use this as a learning artifact. Its length follows the evidence available; do not pad it to a fixed word count or treat it as a publication-ready paper.
