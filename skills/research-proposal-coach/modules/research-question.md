# Research Question Module

## Purpose

Convert a topic direction into answerable research questions.

## Required Inputs

- Selected topic.
- Confirmed real problem.
- Target object and scene.
- Initial method or intervention direction.
- Evaluation angle or expected improvement.

## Coaching Loop

1. Explain the difference between topic, problem, task, outcome, and research question.
2. Draft one core question.
3. Draft up to 3-5 subquestions.
4. Explain whether subquestions are parallel or progressive.
5. Ask the teacher to confirm, merge, delete, or refine.

## Pass Conditions

- The core question has object, scene, problem, method direction, and evaluation angle.
- The teacher confirms the core question.

## Output

```markdown
### Research Questions

Core question:

Subquestions:
1. 
2. 
3. 

Relationship:

Revision notes:
```

## Fallback

If the teacher provides only a title, ask what exact change the project wants to produce and how the teacher would know that change happened.
