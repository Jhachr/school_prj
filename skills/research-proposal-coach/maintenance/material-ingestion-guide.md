# Material Ingestion Guide

Use this guide when adding customer or school materials to the skill's maintained rules.

## Priority Materials

1. School proposal template.
2. Current application guide or call notice.
3. Literature database or retrieval access notes.
4. Excellent proposal examples.
5. Reviewer standards, score sheet, or common rejection comments.
6. School priority directions and professional cluster information.

## How To Summarize Materials

Do not paste sensitive original text into the skill unless permission is explicit. Summarize into:

- What the material changes in the workflow.
- Which stage or module it affects.
- Which source status it supports.
- Which wording or quality rule should change.
- Date and source of the material.

## Where To Put Updates

- Stable quality standards: `rules/reviewer-standards.md`.
- Stage pass/fail rules: `rules/stage-contract.md` or `rules/quality-rubric.md`.
- Output field changes: `templates/proposal-field-mapping.md`.
- Evaluation cases: `maintenance/eval-case-template.md` copied into a dated case file.
- Change rationale: `maintenance/update-log.md`.
